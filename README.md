# Photo Viewer Gallery

A simple Android photo gallery built with Java.

## Features
- Grid of sample photos
- Tap a photo to open it
- Previous and Next navigation
- No storage permission required

## Open
Open this folder in Android Studio and let Gradle sync.

## Build APK
Android Studio: Build > Build Bundle(s) / APK(s) > Build APK(s)

The generated debug APK is normally under:
`app/build/outputs/apk/debug/app-debug.apk`
